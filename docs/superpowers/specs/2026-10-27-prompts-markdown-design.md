# 提示词与回答显示

用户明确要求：可自定义提示词；默认提示词不限定领域、公式或输出结构；正常显示 Markdown；隐藏自动首次提示词，并按实际所用 AI 标注回答。

实现选择：沿用原生 Android Views，使用 Markwon 原生富文本渲染而非手写 Markdown 正则或 WebView。通用、解题、讲解提示词为全局本机设置，主页、预览及回答面板可进入；可保存与恢复默认。通用默认“你是一位学习助手，请根据用户提供的内容和问题提供帮助。”；解题默认“请解答选区中的问题。”；讲解默认“请讲解选区中的内容。”。通用提示词可留空；按钮提示词留空则使用短默认，保证请求有效。

聊天显示与网络上下文分离：自动首问不显示，实际追问保留；请求上下文仍含首问和原图。每条回答记录当时的服务名称，代理地址优先按所选模型识别品牌，未知模型使用用户配置名。流式、取消、重试使用同一显示规则。

Markdown 覆盖标题、加粗、斜体、列表、引用、代码、链接、删除线与基础表格。不启用外部图片下载，不执行 HTML；代码内的 Markdown 标记保留原样。复制按钮复制模型原始回答，避免表格富文本丢失。不在这次修改中加入 LaTeX 排版、联网搜索或变更 API Key 配置。

当前项目没有 Git 仓库，继续在用户指定工作区修改并输出可覆盖安装 APK，不创建仓库或提交。以上技术选择为实施判断；四项产品行为来自用户明确指令，无需重复确认。
