# 圈选 · Freehand Selection

**在 Android 屏幕上随手圈出一块内容，直接向 AI 提问。**

适合阅读 PDF、浏览网页和学习笔记时翻译、理解内容或连续追问。用手指或手写笔沿内容圈选，确认后将选区发给你配置的视觉模型，在悬浮窗里查看回答。

**简体中文** · [English](README.en.md)

## 为什么用圈选

- **按真实路径裁切**：支持不规则、凹形选区，圈外填白，只发送确认的选区图片。
- **无需 Root、Shizuku 或无障碍服务**：使用 Android 系统截图授权和悬浮窗权限；普通手指和手写笔都能操作，不依赖三星 SDK 或 S Pen 特性。
- **自带模型 API（BYOK）**：支持 OpenAI Chat Completions 兼容、Gemini 原生和 Anthropic Messages 三种协议，可保存多套配置并切换。
- **本地用户记忆**：保存回复偏好和学习相关记录，可查看、编辑、删除，也可关闭自动提炼。
- **长对话自动摘要**：整理较早的上下文，保留完整本地历史，方便继续追问。
- **悬浮问答与历史**：回答窗可拖动、缩放，支持流式 Markdown、复制、停止、重试和恢复历史对话。

## 快速开始

要求 **Android 8.0（API 26）及以上**，以及支持图片输入的模型服务。

1. 下载并安装 [0.5.0 调试版 APK](https://github.com/zaron339-cell/Freehand-Selection/raw/refs/heads/main/dist/freehand-selection-0.5.0-debug.apk)。这是当前仓库提供的调试构建。
2. 打开「AI 模型设置」，选择预设或新建配置，填写你自己的 API Key、模型及地址。可先用「测试图片连接」检查连接，再保存。
3. 点「开启悬浮球」，按系统提示授权悬浮窗与屏幕捕获。
4. 切到需要阅读的应用，点悬浮球，沿目标内容自由圈选。
5. 可填写“翻译”“解释原因”等需求，点「确认」发送，在回答窗里继续追问。

也可以先在应用的练习页体验选区和问答。模型服务可能收费，额度及可用性以服务商为准。

## 数据如何处理

历史对话、选区题图和用户记忆保存在应用私有目录，API Key 使用 Android Keystore 加密保存。应用没有自营 AI 后端，请求直接发给你配置的服务地址。

**本地记忆不代表离线 AI。** 问答会发送选区和必要对话；记忆提炼、长对话摘要也会调用配置的模型并产生 API 用量。记忆提炼不额外上传截图。你可以关闭自动提炼或回答时参考记忆。

## 使用前了解

- 需要系统截图授权；受保护内容可能无法捕获，厂商后台管理也可能影响悬浮窗。
- 支持的是上述三类 API 协议；仅支持 Responses 的接口和纯文本模型不能直接用于截图问答。
- 当前没有联网搜题工具，LaTeX 公式以原文显示。
- 跨品牌、分屏、折叠屏和外接显示器兼容性仍需实机验证。
