# 圈选 · Freehand Selection

面向普通 Android 手机和平板的悬浮选区 AI 工具。手指或手写笔可以完成全部操作；不依赖三星 SDK、S Pen 蓝牙、笔侧键、Root、Shizuku 或无障碍服务。

`0.4.1-ball-history`：原尺寸铺屏圈选 → AI 富文本回答和连续追问；回答窗支持独立缩放宽高、移出屏幕及找回，并可长按悬浮球打开历史、继续对话。

## 安装和配置

安装 `dist/freehand-selection-0.4.1-debug.apk`，可覆盖旧版。目标支持 Android 8.0（API 26）及以上；已验证的系统见验证记录。

1. 在主页点「AI 模型设置」。
2. 免费路线选择「智谱免费」，到 [智谱开放平台](https://bigmodel.cn/)注册并创建自己的 API Key，粘贴到应用中。预设模型为 `glm-4.6v-flash`，地址和模型名已填好。
3. 可先点「测试图片连接」：应用发送一张红色测试图片，不含屏幕内容，显示服务商实际返回的文字。测试返回不代表解题准确率已验证。
4. 点「保存并使用」。配置保存在本机，Key 使用 Android Keystore 中的 AES-GCM 密钥加密。APK 不包含开发者或共享 API Key。
5. 点「开启悬浮球」，按系统提示授权，切到 PDF、浏览器或笔记应用，点球进行选区和预览。
6. 确认预览后点「AI 解题」或「讲知识点」，应用才会发送这张选区图片。回答面板支持拖动标题移动、追问、取消、失败后手动重试和复制。

也可以先在练习页验证选区、配置模型和问答，不必先开屏幕共享。

## 窗口与历史对话

- 长按悬浮球打开快捷菜单，点「历史对话」直接弹出悬浮历史列表，点「继续对话」恢复回答窗，不切换当前应用。列表支持滚动及「显示更多」。菜单还提供「开始圈选」和「找回当前回答」（按当前会话状态显示）；单击球仍为圈选或找回回答。
- 拖动回答窗标题移动位置，允许超出屏幕边缘。点悬浮球会把当前回答窗带回屏幕，保留自定义大小。
- 拖右边缘调整宽度、底边调整高度；右下角「↘」同时调整宽高。保留可操作的最小尺寸，最大为当前屏幕尺寸。
- 关闭回答窗会取消当前请求并保存对话。主页「历史对话」可继续或删除，题图、历史署名、未发送草稿和窗口尺寸一并保留。恢复不自动请求 AI，也不要求重新授权截图。
- 生成中的回答约每秒保存一次；强制结束进程可能丢失最后尚未落盘的片段。恢复后可手动重试，或保留未完成片段继续追问。
- 记录和 PNG 题图仅保存在应用私有目录，不自动清理；删除时一起移除。卸载或清除应用数据会清空历史。旧版未保存的已关闭对话无法补回。
- 圈选画面铺满截图画布，工具条浮在上方；拖动工具条标题或提示文字可让开遮挡处。进入裁切预览后工具条归位，预览完整显示选区。

## 自定义提示词与回答显示

主页的「提示词设置」，以及选区预览、回答面板的「提示词」入口，都可编辑三项全局设置，保存后供全部模型的后续请求使用：

- 通用提示词：默认“你是一位学习助手，请根据用户提供的内容和问题提供帮助。”，也可留空以不发送系统提示词。
- AI 解题按钮：默认“请解答选区中的问题。”。
- 讲知识点按钮：默认“请讲解选区中的内容。”。

默认值不要求固定步骤、公式、篇幅、领域或排版，回答形式由模型自行组织。可改成翻译、阅读、历史材料分析等自己的任务；按钮提示词留空会使用简短默认值。「恢复默认」先填入默认文本，点击保存后生效。

自动首问只发送给模型并保留在追问上下文中，不出现在聊天记录。手动追问仍显示为“你：”。回答按生成时使用的模型署名，例如智谱、DeepSeek、Gemini；代理接口优先按模型 ID 识别，未知模型使用用户配置名称。切换模型不改变之前回答的署名。

回答用原生 Markdown 富文本显示标题、黑色加粗、斜体、列表、引用、代码、链接、删除线和基础表格，流式输出也会更新格式。代码和转义标记保持原意。不下载回复中的外部图片，不执行 HTML；只允许手动打开 HTTP/HTTPS 网页链接。复制按钮保留模型原始 Markdown，避免表格内容丢失。

## 免费模型说明

核实日期：2026-10-23。

- **默认：智谱 GLM-4.6V-Flash。** [官方文档](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash)明确标为免费视觉模型，支持图像和流式输出。需要自己的账户和 Key，仍受账户权限与平台限流约束；本应用不承诺永久政策或不受限制的可用性。
- **DeepSeek 预设。** [官方定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)为按量计费，不能当作长期免费 API。当前 `deepseek-flash` 已[支持图像输入](https://api-docs.deepseek.com/guides/vision/)。账户若有赠送余额，以控制台的有效期和余额为准。
- **Gemini 预设。** 使用 `gemini-2.5-flash`，有[免费层](https://ai.google.dev/gemini-api/docs/pricing)，实际配额、地区可用性及账户计费方式由 Google 决定。收费账户的请求不保证免费。

应用不会在免费模型失败后自动切到收费模型，也不会自动重复提交失败请求。

## 使用自己的 API / 切换模型

点「新建配置」，填写名称、接口格式、API 地址、模型 ID 和 Key，保存后可在已保存配置中切换；也可为同一服务商保存不同模型。选区预览和回答面板均有设置入口。

| 接口格式 | 地址填写方式 | 密钥发送方式 |
| --- | --- | --- |
| Chat Completions 兼容 | 填 Base URL，自动补 `/chat/completions`；智谱、DeepSeek、许多代理/本地服务可用 | `Authorization: Bearer …` |
| Gemini 原生 | 例如 `https://generativelanguage.googleapis.com/v1beta`，自动补模型和生成方法 | `x-goog-api-key` |
| Anthropic Messages | 填服务根路径，例如带 `/v1` 的地址，自动补 `/messages` | `x-api-key`，附带协议版本 |

如果服务商给的是完整请求 URL，可勾选「完整请求端点」。支持调整流式开关、15–300 秒总超时、附加请求 JSON。附加参数不能覆盖模型、消息、系统提示和流式开关。

高级配置可指定密钥请求头名称，例如 Azure 风格的 `api-key`；留空按协议默认发送。附加参数中设为 `null` 可移除对应可选参数；指定 `max_completion_tokens` 时自动移除默认的 `max_tokens`，兼容使用新版输出长度参数的模型。

模型需要支持图片输入。“自定义 API”指上述三种格式，不自动适配所有厂商私有协议、仅支持 Responses 的接口或纯文本模型；本版本没有 OCR 降级链路。接到不支持的接口会明确报错。

默认只允许 HTTPS。对于本地或局域网 HTTP 服务，可自行勾选明文连接；此时图片、对话和 Key 会明文发送。Key 可以留空以兼容无需认证的本地服务。

## 对话、图片与网络行为

- 自由圈选按真实路径裁切，圈外填白，保留凹形。预览前不调用 AI。
- 只发送确认的选区；送给模型的图片按最长边不超过 2048 像素编码成白底 JPEG。
- 每次追问携带原选区及本面板中已完成的对话。切换接口后，下一次提问会将这些内容发往新配置的地址；面板显示当前模型与主机。
- 关闭面板取消未完成请求，并把选区题图、完成对话、未完成片段及草稿保存在本地历史；重新打开不自动重发。中断后选择新追问，会保留原片段并标注未完成；重试则重新请求该轮回答。
- 显示准备图片、连接、上传、等待、生成等状态，区分密钥错误、余额不足、限流、超时及协议不匹配。拒绝自动重定向，避免把 Key 与图片转给另一个主机。
- 没有应用自营后端，数据直接发给用户选择的服务商。服务商的数据使用政策需在其平台查看。
- 当前没有联网搜题工具；提示词本身也不能为模型增加联网能力。回答支持原生 Markdown，LaTeX 公式暂以原文显示。
- 分享仍使用系统面板。分享缓存只包含裁切结果，旧缓存会在后续分享时清理；不会把完整屏幕自动保存为图片文件。

## 系统与设备兼容

每次新的 MediaProjection 会话需要系统授权，不复用已消费的 token。Android 14+ 请求整屏捕获；系统或厂商仍可能保留用户选择。锁屏、系统停止共享、进程结束后可能需要重新开启。

横竖屏或捕获尺寸改变时取消旧选区，避免用旧坐标裁错；AI 回答窗口则调整大小。受保护内容可能是黑屏，系统界面可能隐藏悬浮窗。其他品牌后台管理、实体笔误触、分屏、折叠屏和外接显示器仍需实机验证。

## 开发与验证

使用 JDK 17、Gradle 8.4、AGP 8.2.2、Kotlin 1.9.22、SDK 36。AGP 与 compileSdk 36 的组合超出官方验证范围，沿用已有工具链便于本机离线构建；正式发布前应升级并验证。

设置 `JAVA_HOME` 和未跟踪的 `local.properties` 中的 `sdk.dir` 后：

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest :app:checkGeometry :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w io.freehand.selection.test/io.freehand.selection.SelectionInstrumentation
```

设备检查包含原有 11 项选区输入/像素检查，以及真实本地 HTTP 服务上的三种协议、SSE、JSON、图片、追问、密钥加密、401/429、重定向、残缺流和取消。**这些不等于真实服务商账号测试。** 尚无用户 Key，未验证实际免费额度或真实模型的解题结果。

`tools/ai_smoke_server.py`、`tools/ui_smoke.py`、`tools/ui_prompt_smoke.py` 和 `tools/ui_history_smoke.py` 仅用于专用模拟器的本地 UI 验证。模拟回复明确标注“本地模拟接口测试”，不是产品默认接口，不访问真实模型。

主要模块：`CaptureService` / `CaptureSession` 管理悬浮窗与截图；`SelectionCanvas` / `geometry` 处理输入和裁切；`AiProfileStore` 管理加密配置；`AiPromptStore` 管理提示词；`AiWire` 适配协议；`AiClient` 处理网络和取消；`ConversationRenderer` 用 Markwon 4.6.2 渲染回答；各 Settings View 与 `AiConversationView` 提供设置和问答界面。
